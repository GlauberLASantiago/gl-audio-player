# gl-audio-player

Audio player web com foco em desktop, construído com React, TypeScript, Vite e Tailwind CSS.

## Recursos

- Playlist inicial com faixas demonstrativas
- Upload local de arquivos MP3
- Controles de play, pause, anterior, próxima, shuffle e repeat
- Barra de progresso com seek
- Controle de volume e mute
- Visualização simples de áudio com Web Audio API

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Como rodar

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
```
